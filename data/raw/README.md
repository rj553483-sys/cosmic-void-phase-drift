# Raw Catalog Data Access

Due to GitHub file size constraints, large raw astronomical catalogs are not tracked directly in this repository.

### 1. Cosmicflows-4 (CF4) Extragalactic Distance Database (EDD)
* **Source:** Tully et al. (2023)
* **Access Portal:** [http://edd.ifa.hawaii.edu/](http://edd.ifa.hawaii.edu/)
* **Files Needed:** CF4 full group table (`cf4_groups.csv`) and Baryonic Tully-Fisher relation table (`cf4_btf.csv`).

### 2. DESI Data Release 1 (DR1)
* **Source:** DESI Collaboration (2024)
* **Access Portal:** [https://data.desi.lbl.gov/public/dr1/](https://data.desi.lbl.gov/public/dr1/)
* **Catalog:** Luminous Red Galaxy (LRG) value-added catalogs ($z \le 0.5$).
